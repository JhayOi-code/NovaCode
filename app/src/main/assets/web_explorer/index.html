Linq Studio Privacy Policy

Effective Date: November 2026 • LinqStudiosLLC

Linq Studio provides a privacy-first, on-device development environment. We strictly isolate user data, enforce zero-knowledge storage principles, and ensure no unauthorized data sharing occurs.

1. User Data Isolation & Database Locking

All project files, user workspaces, and session records are cryptographically keyed and locked to your unique account identifier. Cross-tenant or unauthorized reads are prohibited at both the API boundary and Firestore security rules levels. Users only ever see and access their own data.

2. Third-Party Services We Transmit Data To

Linq Studio communicates exclusively with the following vetted services:

  • Google Identity & Firebase Authentication: Direct login/sign-up, authentication token issuance, and password reset dispatches. (Data sent: email, username, salted credential hash).
  • Google Cloud Firestore: Encrypted remote persistence for workspace preferences and user account documents. Locked strictly per authenticated user ID.
  • Google Gemini API / Firebase AI Logic: On-demand code suggestions, error diagnosis, and conversational coding assistance. Prompts are transmitted only when user initiates AI queries.
  • Nodemailer / LinqStudiosLLC SMTP Relay: Secure delivery of welcome confirmations, login alerts, and password reset links.
  • User BYOK Providers (OpenAI, Anthropic, Groq, Mistral, DeepSeek): User-configured alternative AI endpoints. Transmitted only if user explicitly inputs an API key. Keys are stored locally on the client.
  • Local On-Device Interpreter / Sandbox: Executes Python, Java, Kotlin, C/C++, Rust, and JavaScript directly inside your sandboxed container or browser without external transmission.

3. Analytics, Cookies & Tracking Policy

We enforce a strict opt-in analytics policy. No tracking pixels, analytics beacons, or session replays are executed unless you explicitly tap "Accept All". If you tap "Reject All", all telemetry remains completely blocked. Session cookies are protected with HttpOnly, Secure, and SameSite=Strict flags.

4. Age Restrictions & Date of Birth

In compliance with COPPA and global youth privacy frameworks, Linq Studio requires users to be at least 13 years old. Date of birth is validated at sign-up to enforce this protection.
